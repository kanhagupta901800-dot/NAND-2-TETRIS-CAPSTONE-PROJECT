2. Part A: Hardware Architecture Verification

The Hack computer architecture combines the Hack CPU, Memory Subsystem (Data RAM16K, Screen, Keyboard), and Instruction ROM32K.

  • ALU (ALU.hdl): Operates on 16-bit operands via 6 control bits, generating arithmetic and logical functions alongside condition flags zr and ng.
  • CPU (CPU.hdl): Decodes A-instructions and C-instructions, driving Register A, Register D, and the Program Counter.
  • Memory (Memory.hdl): Decodes addresses 0x0000..0x3FFF (RAM16K), 0x4000..0x5FFF (Screen), and 0x6000 (Keyboard).
  • Computer (Computer.hdl): Synchronously wires CPU, Memory, and ROM32K into an operational computer.

3. Part B: Two-Pass Python Assembler (assembler.py)

The assembler converts symbolic Hack assembly into 16-bit binary machine code using a two-pass architecture:

  1. Pass 0 & 1: Cleans comments/whitespace and binds code labels (LABEL) to their ROM instruction addresses.
  2. Pass 2: Translates instructions into 16-bit binary codes. Unknown symbols are allocated RAM addresses sequentially starting at RAM[16].

Feature Implementation (K mod 3 = 0):

The assembler outputs comprehensive Assembly Metrics & Code Profiling (total instructions, A/C breakdown) and the Symbol Resolution Table and Memory Allocation Map upon assembly, alongside informative line-number error reporting.

4. Part C: Interactive Box Program (Box.asm)

Box.asm polls the keyboard memory map (RAM[24576]). When pressed, it fills a 16 × 20 pixel box starting at RAM[17920] with black (-1); when released, it paints it white (0).

Progressive Development Steps

  • Step 1 (Step1_Dash.asm): Draws a single 16-pixel word at RAM[17920] = -1.
  • Step 2 (Step2_WideDash.asm): Implements a loop drawing the column words of row 48.
  • Step 3 (Step3_Box.asm): Nested row and column loops painting the 20 rows of row 48 to 67 without keyboard input.
  • Final (Box.asm): Full keyboard-responsive event loop.
